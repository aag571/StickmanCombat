# Combat UI artwork

This skin reuses existing project artwork, without AI generation:

- Paper.png: Assets/Textures/fondo_amarillo.png
- BrushFrame.png: Assets/Textures/shopboard.png
- BrushButton.png: Assets/Textures/menuBTN.png

GameFlowView uses these images for the MainMenu, settings, equipment, results,
unlock panels, and their buttons. Text remains a separate Unity UI element.

The current session has no image generation tool. Replacement generated art
can use the same filenames once generation is available.
